# Hangman Game 🎯

A simple text-based Hangman game built with Python.

## About the Project

This is a beginner-friendly command-line Hangman game. The player has to guess the hidden word one letter at a time. The game keeps track of correct and incorrect guesses and displays the progress of the word.

## Features

* Randomly selects a word from a list
* Allows the player to guess one letter at a time
* Shows correctly guessed letters
* Keeps track of incorrect guesses
* Prevents invalid input
* Displays the final result when the game ends

## Technologies Used

* Python
* `random` module
* Strings
* Lists
* Loops
* Conditional statements
* User input

## How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/MomnaShabir/CodeAlpha-Hangman_Game.git
```

3. Open the project folder:

```bash
cd CodeAlpha-Hangman_Game
```

4. Run the game:

```bash
python main.py
```
